Arena Advantage Profiles

Four-season ATS performance. Team Arena Profile = Home ATS% − Road ATS%. Game-level Arena Advantage triggers when the home team's Home ATS% exceeds the visitor's Road ATS% by at least 8.0 percentage points.

TeamHome ATSHome RecordRoad ATSRoad RecordTeam Arena ProfileProfile RankProfile Tier2026–27 Qualifying Home Games
How this enters Schedule Loss: when a game's home-team Home ATS% minus the visiting team's Road ATS% is +8.0 percentage points or greater, the matchup contributes exactly one arena factor: the home team receives an Arena Advantage and the visitor receives an Arena Disadvantage. In the net red/green classification this changes the matchup by one factor, not two, so it is not double-counted. Other schedule factors can still offset or cancel it.

Data architecture

The page reads data/schedule-database.json as the canonical game database and uses schedule-index-by-date.json and schedule-index-by-team.json for fast calendar and team lookup. This keeps one source of truth while supporting multiple front-end views.
